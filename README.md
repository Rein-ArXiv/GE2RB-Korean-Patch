# GOD EATER 2 Rage Burst 한국어 패치 (비공식)

Steam판 GOD EATER 2 Rage Burst의 비공식 한국어 패치입니다.

- 대사·컷씬 자막·무전·UI·아이템·스킬·불릿·튜토리얼 등 게임 내 텍스트 전반 한국어화
- 원본 게임 파일을 포함하지 않는 바이너리 델타 방식
- 영어 음성 순정판과 Japanese Undub용 패키지를 각각 제공

## 다운로드

[최신 릴리스](https://github.com/Rein-ArXiv/GE2RB-Korean-Patch/releases/latest)에서 환경에 맞는 파일 하나를 받으세요.

- 영어 음성 순정판: `GE2RB_KO_Patch_v1.2.1.zip`
- Japanese Undub 적용판: `GE2RB_KO_Undub_Addon_v1.2.1.zip`

## 일반판 적용 방법

1. Steam 무결성 검사로 게임을 순정 상태로 만듭니다.
2. `GE2RB_KO_Patch_v1.2.1` 폴더를 게임 설치 폴더 안에 넣습니다.
3. 폴더 안의 `apply_patch.bat`을 실행합니다.
4. 순정 확인, 원본 백업, 패치, 결과 검증이 끝날 때까지 기다립니다.

약 11GB의 백업 공간이 필요합니다. 이전 한국어 패치가 적용돼 있다면 `restore_vanilla.bat` 또는 Steam 무결성 검사로 먼저 복원하세요.

## Japanese Undub 적용 방법

1. Steam 순정 상태에서 지원되는 Japanese Undub 전체 교체판을 적용합니다.
2. `GE2RB_KO_Undub_Addon_v1.2.1` 폴더를 게임 설치 폴더 안에 넣습니다.
3. `apply_patch_undub.bat`을 실행합니다.

일본어 음성은 유지되며 `data.qpck`, `bin.qpck`, `bin_patch.qpck`의 한국어 텍스트가 적용됩니다. 일반판 한국어 패치와 동시에 사용하지 마세요. 약 30GB의 백업 공간이 필요합니다.

## 되돌리기

- 일반판: `restore_vanilla.bat` 실행
- 언덥판: `restore_undub.bat` 실행 또는 `.undub` 백업 세 개를 원래 이름으로 복원
- 공통: Steam 게임 파일 무결성 검사로 완전 초기화 가능

## v1.2.1

- 일부 Windows 환경에서 UTF-8 한글 배치가 깨져 명령이 분할되던 문제 수정

- 언덥 애드온에 `bin_patch.qpck` 델타를 포함해 결과 팝업·안내 툴팁 번역까지 적용

배치 화면의 안내 문구가 영어로 표시되는 것은 Windows `cmd.exe` 호환성을 위한 의도된 변경입니다.

## 자주 묻는 질문

**지원되는 원본 파일이 아니라고 나옵니다.**  
다른 패치가 적용됐거나 게임 파일 버전이 다릅니다. Steam 무결성 검사 후 다시 적용하세요. 해시 확인은 잘못된 파일에 바이너리 델타가 적용되는 것을 막기 위한 안전장치입니다.

**게임이 업데이트되면 어떻게 하나요?**  
패치가 풀리거나 적용이 거부될 수 있습니다. 새 게임 빌드에 대응한 패치 업데이트를 기다려 주세요.

**백업 파일을 지워도 되나요?**  
삭제하면 동봉된 복원 배치를 사용할 수 없습니다. 공간이 급하면 삭제할 수 있지만 이후 복원에는 Steam 무결성 검사가 필요합니다.

**세이브 파일은 호환되나요?**  
네. 게임 텍스트 아카이브만 교체하므로 기존 세이브를 그대로 사용할 수 있습니다.

**이전 한국어 패치 위에 바로 설치할 수 있나요?**  
아니요. 복원 배치 또는 Steam 무결성 검사로 해당 패치가 요구하는 시작 상태를 먼저 준비하세요.

## 알려진 사항

- 타이틀 화면의 NEW GAME / CONTINUE와 일부 로고성 문구는 의도적으로 영어를 유지했습니다.
- 다른 버전의 게임 파일이나 지원하지 않는 언덥 구성에는 안전을 위해 패치가 적용되지 않습니다.
- 오역이나 어색한 문장은 [Issues](https://github.com/Rein-ArXiv/GE2RB-Korean-Patch/issues)로 제보해 주세요.
